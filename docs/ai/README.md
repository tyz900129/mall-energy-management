# AI 上下文目录（docs/ai）

本目录为 AI 与开发者提供「按需读取」的系统事实，避免每次通读全仓库。

## 使用方式

1. 先读仓库根目录 [`AGENTS.md`](../../AGENTS.md)（规则层）。
2. 按其中 §6 路由表，只读本次任务相关的 **一张模块卡**。
3. 需要事实清单（接口/表/权限码/模块规模）时，读 `generated/` 下的自动生成文件，不要手抄。
4. 代码与文档冲突时，以代码为准，并顺手修正文档。

## 生成与校验

```bash
# 仓库根目录执行
python scripts/ai/generate-context.py   # 扫描 Controller / 迁移 / 权限码，刷新 generated/
python scripts/ai/check-context.py      # 只读校验：路径、表名、迁移号、权限码、锚点、索引
```

- 修改接口、表、权限码后先跑生成，再跑校验；校验不通过不得合并。
- `generated/` 全部由脚本产出，**禁止手改**，需要新事实就改脚本。
- 校验覆盖：反引号路径是否存在、`- 表：` 行的表名是否存在、权限码是否在代码/迁移中出现、`Vxxx` 是否真实存在、`AGENTS.md` 锚点版本、生成物是否过期、模块卡是否登记。

> `generated/` 的数字随代码变化，以生成文件为准，本文件不重复抄写。

## 新建模块卡

1. 复制 `modules/_template.md`，命名为 `模块名.md`（小写、短横线）。
2. 必填：代码位置、前端页面/API、权限码前缀、表与迁移、入口类、关键不变量、已知坑、测试命令。
3. 在本文件“模块索引”和 `AGENTS.md` §6 路由表中登记。
4. 事实不确定时写“待核实”，不要猜。

## 维护规则

- 改接口、表、权限码、模块边界时，同一批改动内更新对应模块卡。
- 每张卡末尾保留“最后核对：日期 / commit”。
- 不写账号、密码、密钥、生产 IP。
- 事实类内容逐步迁移到 `generated/`，模块卡只保留“为什么”和“坑”。
